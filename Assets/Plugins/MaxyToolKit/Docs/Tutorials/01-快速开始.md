# 01快速开始

## 1.准备工程

确认Unity版本不低于2022.3.62f3，并将项目渲染管线设置为URP

将`MaxyToolKit`文件夹放入项目的`Assets/Plugins`目录

首次导入时等待Unity完成脚本编译。脚本由外部工具修改后，先退出运行模式，再使用MaxyMCP的`request_recompile`刷新并编译

## 2.创建启动对象

在场景中创建空对象，命名为`GameBootstrap`

也可以使用Unity菜单中的`工具/MaxyToolKit/创建游戏启动对象`

在启动对象上挂载负责注册系统的脚本，示例：

```csharp
using MaxyToolKit.Core;
using MaxyToolKit.Tool;
using UnityEngine;

public sealed class GameBootstrap : MonoBehaviour
{
    private void Awake()
    {
        MSystemCenter.Register(new AudioSystem());
    }
}

public sealed class AudioSystem : ISystem
{
    public void Initialize()
    {
        MLog.Log("音频系统初始化");
    }

    public void Shutdown()
    {
        MLog.Log("音频系统关闭");
    }
}
```

## 3.验证是否工作

进入运行模式后，在Unity控制台中查看初始化日志

需要手动重置全部系统时调用：

```csharp
MSystemCenter.Reset();
```
