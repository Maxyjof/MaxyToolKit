# 02事件总线和全局系统

## 全局系统

实现`ISystem`接口即可接入`MSystemCenter`

```csharp
using MaxyToolKit.Core;
using MaxyToolKit.Tool;

public sealed class SaveSystem : ISystem
{
    public void Initialize()
    {
        MLog.Log("存档系统初始化");
    }

    public void Shutdown()
    {
        MLog.Log("存档系统关闭");
    }
}

MSystemCenter.Register(new SaveSystem());
var saveSystem = MSystemCenter.Get<SaveSystem>();
```

系统按照注册顺序初始化，调用`Reset`时按照注册逆序关闭系统

## 定义消息

消息使用普通结构体或类表示，不需要继承框架类型

```csharp
public readonly struct CoinsChanged
{
    public readonly int Value;

    public CoinsChanged(int value)
    {
        Value = value;
    }
}
```

## 发布和订阅

```csharp
using UnityEngine;
using MaxyToolKit.Core;
using MaxyToolKit.Event;
using MaxyToolKit.Tool;

public sealed class CoinService
{
    public void AddCoins(int value)
    {
        Maxy.Events.Publish(new CoinsChanged(value));
    }
}

public sealed class CoinView : MonoBehaviour
{
    private void OnEnable()
    {
        Maxy.Events.Subscribe<CoinsChanged>(OnCoinsChanged).DisposeWith(gameObject);
    }

    private void OnCoinsChanged(CoinsChanged message)
    {
        MLog.Log("当前金币：" + message.Value);
    }
}
```

`DisposeWith(gameObject)`会在对象销毁时自动取消订阅，适用于MonoBehaviour

## 非MonoBehaviour对象

普通C#对象使用`MSubscriptionBag`统一管理订阅

```csharp
using MaxyToolKit.Core;
using MaxyToolKit.Event;

private readonly MSubscriptionBag subscriptions = new MSubscriptionBag();

public void StartListening()
{
    subscriptions.Add(Maxy.Events.Subscribe<CoinsChanged>(OnCoinsChanged));
}

public void StopListening()
{
    subscriptions.Dispose();
}
```
