# 05常见问题和建议

## 修改代码后没有立即编译

如果代码由Unity外部工具修改，先退出运行模式，再调用MaxyMCP的`request_recompile`

该操作会刷新AssetDatabase并请求Unity重新编译。编译完成后使用`get_compilation_errors`检查编译错误

## 事件重复触发

MonoBehaviour使用以下方式订阅：

```csharp
using MaxyToolKit.Core;
using MaxyToolKit.Event;

Maxy.Events.Subscribe<MyMessage>(OnMessage).DisposeWith(gameObject);
```

普通C#对象使用`MSubscriptionBag`，并在对象停止工作时调用`Dispose`

## 系统初始化顺序

系统按注册顺序初始化，按注册逆序关闭。存在依赖关系时，先注册被依赖的系统

## MProperty没有通知

确认是否使用了`SetValueSilently`，该方法不会触发通知

批量更新期间需要调用`EndBatch`，否则通知会一直等待

## 存档读取不到

- 检查读取时的类型和保存时一致
- 检查键名是否完全一致
- 确认Easy Save 3已正确导入
- 不要在存档键中使用空字符串

## 不适合使用MaxyToolKit的场景

- 需要大型依赖注入容器时
- 需要复杂响应式框架时
- 需要跨线程事件总线时
- 需要替换完整存档系统时

MaxyToolKit只提供明确的小型功能，不替代大型架构、依赖注入容器或完整存档方案
