# 04异步、动画和存档

## UniTask等待

```csharp
using Cysharp.Threading.Tasks;
using MaxyToolKit.Async;
using MaxyToolKit.Tool;

private async UniTask ShowMessageAsync()
{
    await MTask.Delay(1f);
    MLog.Log("等待完成");

    await MTask.NextFrame();
    MLog.Log("下一帧执行");
}
```

条件等待：

```csharp
await MTask.WaitUntil(() => isReady);
```

需要取消等待时，将`CancellationToken`传入对应方法

## 淡入淡出

在UI对象上添加`CanvasGroup`和`FadeEffectOverlay`组件

```csharp
using UnityEngine;
using MaxyToolKit.MComponent;
using MaxyToolKit.Integration.MDOTween;

public sealed class ScreenController : MonoBehaviour
{
    [SerializeField] private FadeEffectOverlay overlay;

    public void Open()
    {
        overlay.FadeIn();
    }

    public void Close()
    {
        overlay.FadeOut(0.3f);
    }
}
```

使用DOTween动画时调用扩展方法：

```csharp
overlay.FadeInDOTween(0.3f);
overlay.FadeOutDOTween(0.3f);
```

## 存档

```csharp
using MaxyToolKit.Save;

MSave.Save("player_level", 12);
var level = MSave.Load("player_level", 1);

if (MSave.Exists("player_level"))
{
    MSave.Delete("player_level");
}
```

`MSave`默认将数据写入`Application.persistentDataPath/SaveFile.es3`，不会使用PlayerPrefs。存档键不能为空，建议按系统使用统一前缀，避免不同系统使用同名键

## 正式发布版销毁

在仅用于开发测试的对象上挂载`DestroyInReleaseBuild`

编辑器和Development Build会保留对象；正式发布包运行时会自动销毁该对象
