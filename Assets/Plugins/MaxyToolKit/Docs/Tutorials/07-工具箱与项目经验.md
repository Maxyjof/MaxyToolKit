# 07工具菜单与项目经验

这一篇把「MaxyToolKit 现在提供什么」以及「哪些重复劳动值得收进工具」写清楚，全部可选：不用这些工具也能正常开发

## 1.入口：顶部菜单栏 MaxyToolKit

所有功能都收在 Unity 顶部菜单栏的 `MaxyToolKit` 分类里，点开就是一个下拉列表：

```text
MaxyToolKit
├── PSB 转 UI 预制体        把 PSB 图层结构转成 UI 预制体
├── 打开 PersistentData 目录  存档、日志、缓存都在这里
├── 清理本机 PlayerPrefs 存档 调试前重置本机存档（带二次确认）
├── DOTween 运行统计        运行模式下实时看补间数量与增长趋势
├── 创建游戏启动对象        创建 GameBootstrap 空对象
└── 重置全局系统           清空 MaxyToolKit 的全局系统
```

另外在 Project 窗口右键 `.psb` 也有 `MaxyToolKit/PSB 转 UI 预制体` 入口

## 2.从项目代码里总结出的经验

### 2.1运行时拼 UI 的样板代码太多

项目里临时 UI（彩蛋模式面板、引力弹弓提示、三选一卡面）都要手写一遍新建 GameObject、配 RectTransform、配 TextMeshPro

不只啰嗦，还有一个坑：先激活再配字体/文字时，TMP 会在 `TMP_SubMeshUI.OnEnable` 里报空引用

→ 工具化：`MUIFactory`（运行时），统一「先建未激活 → 配好 → 再激活」的顺序

### 2.2补间容易写得好看但忘了收尾

`DOScale` / `DOFade` / `DOPunchScale` 散落在各个 partial 里，常见问题：

- 忘写 `SetLink`，对象销毁后补间还在跑
- 同一个目标重复触发补间，叠在一起看不出效果
- 时长和缓动各写各的，同一个项目里手感不一致

→ 工具化：`MTween`（运行时）统一先 `DOKill` 再建补间、默认 `SetLink`、内置三档时长

→ 观测手段：`MaxyToolKit/DOTween 运行统计`，Play 下实时看补间数量，数字持续上涨就说明有补间没 Kill

### 2.3PSB 命名决定转换质量

`图层 34`、`从选区 (2)` 这类名字转成 UI 后节点名不可读，也没法套「类型：内容」规则生成按钮/滚动视图

→ 转换窗口里支持命名规则表，图层按 `按钮：开始游戏` 这种格式命名即可自动生成对应结构；不需要时关掉规则开关，只转成纯图片节点

### 2.4调试前重置存档很容易漏

测试「全新开始」时，PlayerPrefs 的 key 分散在多处，手动清容易漏

→ 工具化：`MaxyToolKit/清理本机 PlayerPrefs 存档`，带二次确认，顺手可以打开 PersistentData 目录看存档文件

## 3.运行时工具怎么用（可选）

运行时动效层（转场、提示条、飘字、彩带、打字机、按钮反馈、面板过渡、数字滚动）的完整说明见 `08-运行时动效与转场.md`，这里只列最常用的两个基础类

### 3.1MUIFactory

```csharp
var canvas = MUIFactory.CreateCanvas("临时面板", new Vector2(1920f, 1080f), 100);
var panel = MUIFactory.CreateImage("底图", canvas.transform, sprite, new Color(1f, 1f, 1f, 0.9f));
MUIFactory.Stretch(panel.rectTransform, 40f);
var label = MUIFactory.CreateText("标题", panel.transform, "测试文本", font, 32f);
var button = MUIFactory.CreateButton("确定", panel.transform, "确定", () => Debug.Log("点击"), sprite, font);
MUIFactory.StyleButtonColors(button, Color.white, new Color(1f, 0.96f, 0.86f), new Color(0.88f, 0.84f, 0.74f));
```

不需要替换项目里已有的拼 UI 代码，只有新写的临时界面用得上就用

### 3.2MTween

```csharp
MTween.ScalePop(panel.transform);                       // 从 0.9 弹回 1
MTween.Punch(icon.transform);                           // 点击反馈
MTween.Fade(label, 0f, MTween.Fast);                    // 淡出
MTween.SlideIn(panel.rectTransform, new Vector2(0f, -24f)); // 从下方滑入
```

时长只有三档（`Fast` 0.16 / `Normal` 0.24 / `Slow` 0.4），需要更细的控制时直接用 DOTween 原生接口，`MTween` 只负责统一手感和防泄漏

## 4.PSB 转 UI 预制体

支持的结构与命名规则见 `06-PSB转UI预制体.md`，核心点：

- 命名规则是可选开关，关闭时只生成 RectTransform + Image
- 开启后按「类型：内容」生成按钮、文本、滚动视图、下拉框、页签组、开关、滑动条、输入框、遮罩、原图等结构
- 结构都按 Unity 默认创建 UI 的层级搭，方便直接沿用官方工作流
