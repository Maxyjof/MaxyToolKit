# 08运行时动效与转场

这一篇是 MaxyToolKit 运行时动效层的使用说明，全部可选：项目里已有的 `Fate*` 动画组件不需要替换，这些是给新界面、临时界面和后续项目复用的

## 1.转场：MTransition

全屏淡入淡出，遮罩对象按需创建、跨场景复用，不占用场景资源

```csharp
//切场景前盖住画面
MTransition.FadeOut(Color.black, 0.25f, () =>
{
    SceneManager.LoadScene("Gameplay");
    //新场景准备好后淡入
    MTransition.FadeIn(0.3f);
});

//半透明压暗（弹大面板前）
MTransition.FadeTo(0.6f, new Color(0f, 0f, 0f, 1f), 0.2f);

//直接设置，不做动画
MTransition.SetAlphaImmediate(0f);
```

- `MTransition.IsBusy` 可以判断当前是否在转场
- 遮罩排序值 32000，永远盖在最上层；可见时阻挡点击，避免过渡期间误触
- 时间走 `unscaledTime`，暂停状态下也能正常过渡

## 2.提示条：MToast

顶部弹出短提示，自动排队，不需要在场景里摆对象

```csharp
MToast.Show("已保存");
MToast.Show("银两不足", 1.2f);
MToast.Show("获得神器「猫神之瞳」", -1f, new Color(0.1f, 0.08f, 0.05f, 0.9f), Color.white);
```

- 首次调用自动创建播放器画布（排序 31000），之后复用
- 默认显示 1.8 秒；`duration` 传 -1 用默认值
- 背景色 / 文字色 / 字体都可通过重载或 `MToast.DefaultBackground`、`MToast.DefaultFont` 全局调整

## 3.补间工具：MTween（本次扩展）

在原有 `Fade / ScalePop / Punch / SlideIn / SlideOut / CountTo / KillSafe` 之外新增：

| 方法 | 用途 |
| --- | --- |
| `CanvasGroupFade(group, alpha, duration)` | 整组淡入淡出 |
| `Shake(target, strength, duration)` | 位置抖动（受击、错误提示） |
| `ScaleTo(target, scale, duration)` | 平滑缩放到指定值 |
| `Move(rect, position, duration)` | 平滑移动到锚点位置 |
| `Blink(graphic, times, interval)` | 闪烁警告 |
| `DelayedCall(seconds, action)` | 延迟回调（走 unscaledTime） |

所有方法都自动 `DOKill` 并 `SetLink`，不会在对象销毁后留下补间

## 4.通用动效组件

### 4.1MButtonFeedback

挂在按钮或任意带 Graphic 的物体上，悬停提亮放大、按下缩小

```csharp
button.gameObject.AddComponent<MButtonFeedback>();
```

### 4.2MPanelTransition

面板开合动画，`OnEnable` 自动播入场（可关），支持退出

```csharp
panel.gameObject.AddComponent<MPanelTransition>();
//手动播放
panelTransition.PlayEntrance();
panelTransition.PlayExit(() => Debug.Log("收起了"));
panelTransition.SetVisibleImmediate(false);
```

### 4.3MNumberText

数字滚动，要求同物体上有 `TMP_Text`

```csharp
numberText.SetValue(1234);          // 滚动到 1234
numberText.SetValueImmediate(1234); // 直接跳
```

### 4.4MTypewriter

打字机文字，要求同物体上有 `TMP_Text`

```csharp
typewriter.Play("今天也要收集天命碎片");
typewriter.SkipToEnd();
```

## 5.特效

### 5.1MFloatingText

分数/伤害飘字

```csharp
MFloatingText.Spawn(canvasRect, new Vector2(0f, 100f), "+120", new Color(1f, 0.85f, 0.3f));
MFloatingText.SpawnAt(canvasRect, worldPosition, "暴击", Color.red);
```

### 5.2MConfetti

UI 层彩带礼花，不依赖粒子系统

```csharp
MConfetti.Play(canvasRect);
MConfetti.PlayAt(canvasRect, new Vector2(0f, 200f), 32, 1.1f);
```

## 6.和 MUIFactory 配合的典型用法

```csharp
//一个会飘出来的奖励提示
var panel = MUIFactory.CreateImage("奖励条", canvasRect, sprite, new Color(1f, 1f, 1f, 0.95f));
panel.rectTransform.sizeDelta = new Vector2(420f, 120f);
MUIFactory.CreateText("标题", panel.transform, "获得奖励", font, 28f);
MTween.ScalePop(panel.transform);
MToast.Show("奖励已放入背包");
```
