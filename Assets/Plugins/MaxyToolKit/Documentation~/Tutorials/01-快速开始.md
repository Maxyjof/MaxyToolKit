# 01快速开始

## 1准备工程

确认Unity版本不低于2022.3.62f3，并且项目使用URP

将`MaxyToolKit`文件夹放入`Assets/Plugins`

首次导入时等待Unity完成脚本编译。若脚本由外部工具修改，使用MaxyMCP的`request_recompile`刷新并编译

## 2创建启动对象

在场景中创建一个空对象，命名为`GameBootstrap`

也可以使用Unity菜单中的`工具/MaxyToolKit/创建游戏启动对象`

在启动对象上挂载负责注册系统的脚本

```csharp
using MaxyToolKit;
using UnityEngine;

public sealed class GameBootstrap : MonoBehaviour
{
    private void Awake()
    {
        MSystemCenter.Register(new AudioSystem());
    }
}

public sealed class AudioSystem : ISystem
{
    public void Initialize()
    {
        MLog.Log("音频系统初始化");
    }

    public void Shutdown()
    {
        MLog.Log("音频系统关闭");
    }
}
```

## 3验证是否工作

进入运行模式后，在Console中应该看到初始化日志

如果需要手动重置全部系统，可以调用：

```csharp
MSystemCenter.Reset();
```
