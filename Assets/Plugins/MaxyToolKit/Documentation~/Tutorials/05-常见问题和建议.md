# 05常见问题和建议

## 修改代码后没有立即编译

如果代码由Unity外部工具修改，调用MaxyMCP的`request_recompile`

它会刷新AssetDatabase并请求Unity重新编译。编译完成后使用`get_compilation_errors`检查错误

如果Unity处于运行模式，先退出运行模式再请求编译

## 事件重复触发

MonoBehaviour优先使用：

```csharp
Maxy.Events.Subscribe<MyMessage>(OnMessage).DisposeWith(gameObject);
```

普通C#对象使用`MSubscriptionBag`，并在对象结束工作时调用`Dispose`

## 系统初始化顺序

系统按注册顺序初始化，按注册逆序关闭。存在依赖关系时，先注册被依赖的系统

## MProperty没有通知

确认是否使用了`SetValueSilently`，该方法不会触发通知

批量更新期间需要调用`EndBatch`，否则通知会一直等待

## 存档读取不到

- 检查读取时的类型和保存时一致
- 检查键名是否完全一致
- 确认Easy Save 3已正确导入
- 不要在存档键中使用空字符串

## 什么时候不应该使用MaxyToolKit

- 需要大型依赖注入容器时
- 需要复杂响应式框架时
- 需要跨线程事件总线时
- 需要替换完整存档系统时

MaxyToolKit的目标是提供清晰的小工具，而不是覆盖所有架构需求
