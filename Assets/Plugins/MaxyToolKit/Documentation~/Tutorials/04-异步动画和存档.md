# 04异步、动画和存档

## UniTask等待

```csharp
using Cysharp.Threading.Tasks;
using MaxyToolKit;

private async UniTask ShowMessageAsync()
{
    await MTask.Delay(1f);
    MLog.Log("等待完成");

    await MTask.NextFrame();
    MLog.Log("下一帧执行");
}
```

条件等待：

```csharp
await MTask.WaitUntil(() => isReady);
```

需要取消等待时传入`CancellationToken`

## 淡入淡出

在UI对象上添加`CanvasGroup`和`FadeEffectOverlay`

```csharp
public sealed class ScreenController : MonoBehaviour
{
    [SerializeField] private FadeEffectOverlay overlay;

    public void Open()
    {
        overlay.FadeIn();
    }

    public void Close()
    {
        overlay.FadeOut(0.3f);
    }
}
```

需要DOTween时使用扩展方法：

```csharp
overlay.FadeInDOTween(0.3f);
overlay.FadeOutDOTween(0.3f);
```

## 存档

```csharp
MStorage.Save("player_level", 12);
var level = MStorage.Load("player_level", 1);

if (MStorage.Exists("player_level"))
{
    MStorage.Delete("player_level");
}
```

存档键不能为空，建议使用统一前缀避免不同系统重名

## 发布版销毁

在只用于开发测试的对象上挂载`DestroyInReleaseBuild`

编辑器和Development Build会保留对象，正式发布包运行时会自动销毁对象
