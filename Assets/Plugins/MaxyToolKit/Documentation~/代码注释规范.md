# MaxyToolKit代码注释规范

## 适用范围

本规范适用于MaxyToolKit自有Runtime与Editor源码，不适用于Plugins目录中的第三方库源码

## XML注释规则

- 每个类、接口、委托和方法都应提供中文XML注释
- XML标记必须单独占一行
- 方法参数使用独占行的`<param>`标记说明，非`void`返回值使用独占行的`<returns>`标记说明，泛型参数使用独占行的`<typeparam>`标记说明
- 说明文字末尾不使用句号或其他句末标点
- 中文和英文之间不添加空格
- 术语保持稳定，例如`ScriptableObject`、`UI`、`Animator`、`Transform`不翻译
- 复杂方法可使用`<remarks>`补充调用顺序、线程、生命周期或异常注意事项

## 行内注释规则

- 双斜线注释使用`//注释内容`格式，双斜线与正文之间不添加空格
- 复杂方法按验证、状态更新、事件通知、资源清理等逻辑分段添加行内注释
- 行内注释末尾不使用句号或其他句末标点
- 注释只解释意图与约束，不重复明显的语法

## 示例

```csharp
/// <summary>
/// 管理全局系统的注册、查询和生命周期
/// </summary>
public static class MSystemCenter
{
    /// <summary>
    /// 注册一个全局系统并执行初始化
    /// </summary>
    /// <typeparam name="T">
    /// 系统类型
    /// </typeparam>
    /// <param name="system">
    /// 要注册的系统实例
    /// </param>
    /// <param name="replace">
    /// 已有同类型系统时是否先移除旧实例
    /// </param>
    /// <returns>
    /// 传入的系统实例
    /// </returns>
    public static T Register<T>(T system, bool replace = false) where T : class
    {
        //验证参数并处理同类型系统
        return system;
    }
}
```
